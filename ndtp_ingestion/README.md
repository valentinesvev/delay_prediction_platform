Техническая документация: NDTP Ingestion (TCP-сервер)

1. Общее описание модуля: Микросервис-обработчик входного потока (Data Ingestion). Принимает TCP-соединения от NDTP-эмулятора, выполняет рукопожатие (handshake), декодирует бинарные телематические пакеты и нормализует координаты. Модуль работает автономно и выступает поставщиком очищенных данных для ML-ядра.

2. Архитектура и База данных: Используется единая база данных SQLite (transport_data.db) со следующей структурой:

telemetry: Фактические данные. Время записывается строго в UTC.

schedule_plan: Плановое расписание маршрутов. Инициализируется из schedule.csv. Фактическое время исключено во избежание утечки данных.

predictions: Таблица для записи прогнозов ML-модулем.

Garbage Collector: Асинхронный процесс каждые 10 минут удаляет из базы телеметрию старше 2 часов.

3. Спецификация парсера NDTP:

Handshake: Обрабатывается пакет NPH_SGC_CONN_REQUEST (тип 100).

Телеметрия: Обрабатывается пакет NPH_SND_REALTIME (тип 101).

Навигация: Парсинг ячейки G6CellNav00 (тип 0, 26 байт) в формате little-endian.

4. Инструкция по развертыванию (Docker):

docker build -t ndtp-server .

docker run -d -p 9000:9000 --name ndtp-ingestion ndtp-server
